# KODEX 마케팅 AI Agent (Streamlit)

PPT(AI Agent 구축 및 활용 방안) 기반의 섹션형 통합 모니터링 대시보드.
탭 구조의 한계(분석 중단·결과 소실)를 해소하기 위해 전 섹션을 한 화면에 배치했습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 구성

| 섹션 | 내용 |
|------|------|
| 상단 위젯 | 코스피·코스닥·환율 실시간 조회 (네이버 증권, 5분 캐시, 실패 시 데모 값) |
| **Section 1 · 핵심** | **시장 순매수 분석** — 순매수강도 TOP N + DiD 이중차분 4단계 (처치군/대조군 선택, 순효과 계량화) |
| **Section 2 · 핵심** | **테마 분석** — 테마별 주간 수익률, 수익률×매수강도 버블맵, 라이징/하락 테마, Gemini's Pick |
| Section 3 | ETF 이슈 키워드 + 4대 운용사(KODEX·TIGER·RISE·ACE) 동향 요약 |
| Section 4 | AI 종합 마케팅 인사이트 — 카드형 UI |

## 데이터

- 순매수·테마 데이터는 `data.py`의 데모 생성기 사용. 사이드바에서 **엑셀 업로드**
  (컬럼: 주차·종목명·테마·운용사·순매수액·순자산) 시 실데이터로 대체됩니다.
- 실운영 시 `data.py`의 각 함수를 KRX·구글뉴스·유튜브 API·Gemini 연동부로 교체하면 됩니다.

## 핵심 산식

- **매수강도** = (주간 순매수액 ÷ 전주 순자산) × 100
- **DiD 순효과** = (처치군 금주−전주 매수강도) − (대조군 금주−전주 매수강도)
  - 대조군 미지정 시 단순 변화량만 표시 (시장효과 미제거 명시)
